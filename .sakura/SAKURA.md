## 一、字体下载子系统审查（PR #27 核心教训）

### 1.1 问题发现

PR #27 的增量审查仅聚焦"排版优化"，遗漏了**引入的新子系统**：`_load_cn_font()` 函数包含网络下载和临时文件管理。

**关键遗漏**：
- 网络下载的超时设置
- 下载失败时的降级路径
- 临时目录的清理机制
- 多线程场景下的缓存安全性

### 1.2 下载类操作必查清单

```
□ HTTPS 链接是否存在
□ 是否有完整性校验（hash/签名）
□ 是否有超时机制
□ 下载失败时的降级/报错策略
□ 临时文件清理机制
□ 磁盘空间不足的处理
```

### 1.3 临时文件审查要点

```
□ 使用后是否显式关闭
□ 是否设置了合理的生命周期
□ 长期运行进程是否会导致 /tmp 膨胀
□ 异常路径下是否也会清理
□ 是否依赖 delete=True（不足以保证清理）
```

### 1.4 增量审查的正确边界

```
quick 策略下：
- 仍聚焦增量功能本身
- 但需明确标注"未审查区域"
- 增量引入新子系统（网络/文件/线程）时，应触发完整审查
- 不应将"功能实现正确"等同于"代码健壮性合格"
```

### 1.5 字体下载/缓存场景审查经验

1. 优先使用系统字体，避免网络下载
2. 若必须下载，验证 SHA256
3. 使用 `shutil.rmtree` 清理缓存，而非依赖 `delete=True`
4. 多线程场景加锁或使用单例模式

## 二、Issue 分类与标签规范

### 2.1 分类准确性要求

**常见错误**：将 UI 样式问题分类为 `other` 或 `bug`

| 问题类型 | 正确分类 | 说明 |
|----------|----------|------|
| 字体显示、样式不一致 | `enhancement` 或 `UI` | 功能未达期望，非程序错误 |
| 气泡框排版问题 | `UI` 或 `enhancement` | 视觉调整类 |
| 程序崩溃、功能完全不工作 | `bug` | 明确的功能失效 |

**区分标准**：
- `bug`：程序崩溃、功能完全不工作
- `enhancement`：功能未达到期望体验、体验优化

### 2.2 标签推荐（强制要求）

**所有 PIL/绘图类 Issue 必须包含**：

| 标签 | 置信度 | 理由 |
|------|--------|------|
| `PIL/pillow` | 0.85+ | 字体渲染依赖 pillow |
| `layout` | 0.80+ | 涉及排版/布局调整 |
| `style` | 0.75+ | 视觉样式问题 |
| `beginner` | 0.70+ | 纯参数调整，适合新手 |

**字体类 Issue 额外标签**：
- `font` | 0.85+
- `rendering` | 0.80+

### 2.3 标签-分类一致性

| 分类 | 常见矛盾标签 | 处理方式 |
|------|-------------|----------|
| `enhancement` | `bug` | 必须移除 `bug` 标签 |
| `bug` | `enhancement` | 可保留，两者是不同的维度 |

## 三、截图引用与标题改写规范

### 3.1 截图查看清单（PIL/UI 类 Issue 必查）

```
截图查看结果：
- 观察到的布局特征：头像位置、气泡框间距、整体紧凑程度
- 与当前实现的差异：当前参数 vs 期望参数对比
- 修改边界：需覆盖截图中的所有元素位置
```

**禁止表述**：仅说"已查看截图"而不描述内容。
**最低要求**：即使只描述"截图中用户指出了字体位置"也比完全不提及好。

### 3.2 标题改写规范

| 情况 | 操作 |
|------|------|
| 原标题 ≥ 5 字且清晰 | 不改写 |
| 原标题 < 5 字或无意义（如"bug"、"问题"、"逗号"） | 改写为描述性标题 |
| 任何情况 | ❌ 禁止添加 `[分类]` / `[优先级]` 前缀 |

**越权示例**（严重违规）：
```
❌ 错误：[bug][medium] 生成图片字体与聊天框显示不一致
✅ 正确：生成图片字体与聊天框显示不一致
```

### 3.3 可行性评估要求

```
❌ 禁止："无法评估"
✅ 正确：根据描述至少判断"高/中/低工作量"和涉及模块
```

## 四、坐标联动检查与敏感操作边界

### 4.1 坐标联动检查清单（PIL/坐标类 Issue）

```
边界检查清单：
□ 水平边界：文字宽度是否超出容器
□ 垂直边界：元素高度变化是否影响间距
□ 对齐关系：头像与气泡框的相对位置
□ 坐标联动：头像尺寸变化后气泡框坐标是否联动调整
□ 文字溢出：紧凑后长文本是否需要额外换行
```

### 4.2 敏感操作边界检查清单

```
□ 资源获取：是否有竞态条件
□ 资源释放：异常路径是否也会释放
□ 网络操作：超时、重试、失败处理
□ 文件操作：权限、空间、路径遍历
□ 配置依赖：硬编码值是否有配置化需求
```
