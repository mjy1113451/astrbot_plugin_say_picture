## 6. 经验教训

### 6.1 本次核心问题
1. **越权改写标题** — 对规范理解错误，需重新学习规范 1.3
2. **截图处理流于形式** — "已查看"不等于"已分析"，需逐像素比对
3. **置信度未按场景调整** — 图片 Issue 应统一下调

### 6.2 本项目特定注意事项
- **PIL 绘图优化类 Issue** 通常工作量小但细节多：
  - 阴影需调参（偏移、模糊、透明度）
  - 渐变需计算像素级过渡
  - 应给出**可分步验证的方案**（先阴影→再渐变→最终调参）
- **坐标联动**容易遗漏：调整气泡框尺寸时，文字换行逻辑可能失效

### 6.3 未来审查清单
```
□ 标题改写：是否越权添加分类标签？
□ 截图分析：是否引用了具体视觉元素？
□ 优先级：是否区分了"功能影响"和"纯UI调整"？
□ 边界检查：是否有 textwrap/文字溢出检查？
□ 标签补充：是否遗漏 style/visual/shadow/good-first-issue？
```
