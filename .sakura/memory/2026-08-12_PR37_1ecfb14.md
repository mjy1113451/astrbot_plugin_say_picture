## 四、经验教训

### 4.1 本次核心问题

| 问题 | 根因 |
|------|------|
| 数值验证缺失 | Quick 模式时间压缩导致跳过基础检查 |
| 极端情况未覆盖 | 缺乏布局变更的标准化审查流程 |
| 升级条件执行不一致 | 规范标注"强制"但未被执行 |

### 4.2 未来审查关注点

1. **布局变更 ≠ 小改动**：坐标变更可能引发级联影响（头像、三角、文字三者联动）
2. **描述与代码的映射**：PR 描述说"贴气泡顶部偏上"→需验证 `bubble_y0 - 10` 确实符合语义
3. **三角指针的特殊性**：等腰三角形的位置变化涉及两个坐标（x 和 y），需同步验证

### 4.3 审查建议

本次审查的**主要改进方向**：

```
1. 强制执行数值代入验证（至少 3 组测试用例）
2. 布局变更统一升级为完整审查
3. 建立"变更描述 → 代码验证"的强制映射检查
```
