**分类**：`enhancement` ✓ 准确。这是明确的 UI 改进请求。

**优先级**：`medium` ⚠️ 基本合理但值得商榷

- 缺点：仅是坐标调整，功能不受影响，部分团队可能评为 `low`

**遗漏标签**：

**不足之处**：

✓ 准确。此类特定 UI 调整请求重复概率低。
