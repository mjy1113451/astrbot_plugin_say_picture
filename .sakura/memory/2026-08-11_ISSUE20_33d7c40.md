## 6. 经验教训

### 值得关注的要点

| 教训 | 说明 |
|------|------|
| **避免沿用原标签** | 应独立分析后给出自己的判断，再与原标签对比 |
| **可行性建议要具体** | 给出明确坐标值，而非"例如" |
| **引用 Issue 附件** | 有截图时应标注具体位置 |
| **置信度评估需保守** | 仅基于标题时，0.95 明显偏高 |
| **标签可适当扩展** | UI 类 Issue 可考虑添加 `beginner` 等标签 |

### 对仓库的分析建议

这是一个**图片生成插件**，涉及大量 PIL 绘图的坐标参数调整。未来类似 Issue 可能：
- 涉及多个文本/元素的坐标联动调整
- 需要考虑不同字体大小下的适配问题
- 可能涉及多语言/多长度文本的边界情况

建议在可行性分析时增加：**"此修改是否可能影响其他元素布局"** 的评估维度。
