## 6. 经验教训

### 对未来分析的启示

| 要点 | 具体建议 |
|------|---------|
| **可行性 ≠ 工作量** | 1行代码不一定=low，需综合考虑 UI 影响范围 |
| **固定坐标风险** | 标注位置调整时，需确认目标区域是否动态变化 |
| **标签适度** | 核心标签1-2个足够，过多标签反而降低可用性 |
| **标题改写阈值** | 仅在原标题模糊/冗余时改写，避免画蛇添足 |

└── 标签建议：enhancement + UI
