## 七、经验教训

### 1. 方括号标签解析策略

Issue 标题中的 `[enhancement][low]` 格式应被正确解析：
- 第一个标签 → 分类依据
- 第二个标签 → 用户自评优先级

不应将其视为"异常标题"而跳过关键信息提取。

### 2. 技术性失败的处理规范

当分析流程因格式问题崩溃时：
```
技术性失败 ≠ 真正无法评估
```

**正确流程**：
1. 记录格式解析失败原因
2. 尝试基于摘要内容重新评估
3. 若仍失败，标记为"待人工处理"
4. **绝不应**标记为"无法评估"并终止

### 3. UI 类 Issue 的自动标签关联

涉及图像、布局、样式调整的 Issue，应自动关联：
- `style` / `layout` / `ui`
- `PIL` / `image-processing`

### 4. 摘要错误暴露的问题

`missing </SUGGESTED_TITLE>` 表明输出格式校验失败，但最终用户看到的只是"无法评估"。应提供更清晰的错误信息，帮助定位问题根因。
