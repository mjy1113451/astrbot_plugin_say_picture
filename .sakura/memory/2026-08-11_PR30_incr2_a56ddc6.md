## 四、经验教训

### 值得关注的要点

1. **超时设置的最佳实践**：
   ```python
   # ❌ 全局设置，影响所有请求
   socket.setdefaulttimeout(30)
   
   # ✅ 单次请求设置，精确控制
   urllib.request.urlopen(url, timeout=30)
   ```
   增量审查应识别这类从"精确"变为"模糊"的做法

2. **导入位置的双重意义**：
   - 文件顶部导入：符合 PEP8、IDE 支持好
   - 函数内导入：避免循环依赖、延迟加载
   两者都有合理场景，需结合上下文判断

3. **quick 模式的边界**：
   quick 不等于"不检查安全问题"。即使只看增量，全局副作用和调用链风险仍需评估
