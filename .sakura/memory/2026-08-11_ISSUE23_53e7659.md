## 6. 经验教训

### 关键发现

| 教训 | 说明 |
|------|------|
| **截图必须检查** | UI 类 Issue 通常有截图对比，分析中应明确说明是否查看 |
| **边界风险不可忽视** | 缩小尺寸后，文字溢出风险需要评估 |
| **good-first-issue 标签** | 工作量小的 Issue 应考虑添加此标签 |
| **标题改写需谨慎** | 仅当原标题不清晰时才改写 |

### 未来建议

1. **UI/坐标类 Issue 必须执行边界检查**
   ```
   □ 缩小后文字宽度是否超出气泡框？
   □ 元素间距是否协调？
   □ 截图是否查看？
   ```

2. **记录重复检测过程**
   ```
   检索词: "头像" + "缩小" + "比例"
   结果: 未发现重复
   ```

3. **标题改写原则**：仅当原标题存在歧义或信息缺失时才改写
