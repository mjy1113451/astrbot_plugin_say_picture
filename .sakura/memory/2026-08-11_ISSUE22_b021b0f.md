## 六、经验教训总结

### 1. UI/坐标类 Issue 必须检查清单

本次分析遗漏了以下检查项：

- [ ] **边界检查**：文字放大后是否超出容器？
- [ ] **附件查看**：用户是否提供了截图？期望位置如何？
- [ ] **联动影响**：调整一个元素是否影响其他元素？
- [ ] **多语言适配**：其他语言版本是否需要同样调整？

### 2. 置信度管理

```
仅标题关键词 → 0.70-0.85（不宜 0.95）
+ 代码依据 → 0.85-0.90
+ 截图确认 → 0.90-0.95
图片 Issue 视觉解读存在不确定性，置信度应适度下调
```

### 3. 仓库特定模式

本仓库（AstrBot 图片生成插件）涉及 PIL 绘图，未来分析类似 Issue 应：
- 明确当前使用的字体文件
- 说明坐标系统（相对气泡框还是绝对坐标）
- 考虑 DPI/分辨率对坐标的影响

### 4. 本次分析的核心不足

> **未查看用户附件**，导致无法确认"往下一点"的具体期望位置，仅能给出范围建议（y=50-60）。
