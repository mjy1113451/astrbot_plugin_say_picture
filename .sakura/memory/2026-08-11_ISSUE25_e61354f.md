## 6. 经验教训与改进建议

### 6.1 关键失误

**最严重问题：未查看截图附件**

```
□ 截图是否查看？→ 否（分析结果未引用截图内容）
□ 期望位置是否从截图确认？→ 否
```

用户明确附带了截图，但分析完全未引用。这是**违反硬性要求**的错误。

### 6.2 体系化改进

| 问题类型 | 预防措施 |
|----------|----------|
| 附件遗漏 | 增加"附件引用检查"步骤，强制要求引用截图内容 |
| 方案笼统 | 可行性判断增加"最小可验证方案"要求 |
| 标签不足 | 建立标签数量下限（≥3个）和必含标签清单 |
| 标题过度改写 | 增加"改写必要性"评估环节 |

### 6.3 项目特定注意事项

结合本仓库特点（AstrBot 插件、PIL 绘图）：

1. **PIL 版本差异**：不同版本 API 可能有变化（如 `ImageFont.getsize` 在新版本已弃用）
2. **字体回退机制**：必须考虑用户系统字体差异
3. **坐标固定性**：本项目气泡框坐标基于固定画布，调整时需重新计算所有相对位置
